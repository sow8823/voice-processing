# 画面一覧

## 1. メイン画面

現在のアプリケーションには単一の画面があり、以下のコンポーネントで構成されています：

### 1.1 ヘッダー
- アプリケーション名「音声ピッチ分析」の表示
- 情報アイコンボタン

### 1.2 音声入力セクション
- 「音声ピッチ検出と周波数特性」タイトル
- 「音声のピッチと周波数特性をリアルタイムで分析します」サブタイトル
- 音声入力モード選択タブ
  - 「リアルタイム」タブ
  - 「録音と再生」タブ
  - 「ファイル読み込み」タブ

#### 1.2.1 リアルタイムモード
- 「マイクを使用してリアルタイムで分析します」説明テキスト
- 「音声処理を開始」ボタン
- 処理中の状態表示（録音中アラート）

#### 1.2.2 録音と再生モード
- 「録音して保存し、後で再生しながら分析できます」説明テキスト
- 録音コントロール
  - 「録音開始」ボタン
  - 「録音停止」ボタン
  - 録音時間表示
- 再生コントロール
  - 「再生」ボタン
  - 「一時停止」ボタン
  - 「停止」ボタン
  - 再生位置スライダー
  - 再生時間/総時間表示
- 録音リスト
  - 保存された録音の一覧
  - 各録音の削除ボタン

#### 1.2.3 ファイル読み込みモード
- 「外部で録音した音声ファイルを分析できます」説明テキスト
- ファイル選択
  - 「ファイルを選択」ボタン
  - 選択されたファイル名表示
- 再生コントロール
  - 「再生」ボタン
  - 「一時停止」ボタン
  - 「停止」ボタン
  - 再生位置スライダー
  - 再生時間/総時間表示

### 1.3 ピッチ検出セクション
- ピッチ検出のタイトル
- ピッチ表示キャンバス
  - 現在のピッチ値（Hz）
  - 対応する音階（例：A4）
  - ピッチの視覚的表示（0-2000Hz範囲）

### 1.4 周波数スペクトルセクション
- 周波数スペクトルのタイトル
- スペクトル表示キャンバス
  - リアルタイムの周波数スペクトル（0-10000Hz範囲）
  - 基本周波数、2倍音、3倍音のマーカー表示
- 分析データ表示
  - 2倍音強度（基音との比率、%）
  - 3倍音強度（基音との比率、%）
  - 2.8kHz~3.2kHz帯域の最大成分（基音との比率、%）

### 1.5 周波数ヒートマップセクション
- 周波数ヒートマップのタイトル
- カラーレジェンド（低強度から高強度へのグラデーション）
- ヒートマップ表示キャンバス
  - 時間経過に伴う周波数スペクトルの変化
  - 周波数軸（縦）と時間軸（横）
- 分析データ表示
  - 2倍音強度平均（%）
  - 3倍音強度平均（%）
  - 2.8kHz~3.2kHz帯域の最大成分平均（%）

### 1.6 フッター
- コピーライト情報「© 2025 - 音声ピッチ分析ツール」

## 2. 将来的な画面案

### 2.1 トレーニング履歴画面
- ユーザーの過去のトレーニングセッションの記録と分析結果の表示
- 時系列でのピッチや音質の変化グラフ
- トレーニング進捗の可視化

### 2.2 トレーニングプログラム画面
- 特定の声質や技術向上のためのトレーニングプログラムの提示
- ステップバイステップのエクササイズガイド
- 目標設定と達成度の表示

### 2.3 分析レポート画面
- 詳細な音声分析レポートの生成と表示
- 強み・弱みの分析
- 改善のためのアドバイス

### 2.4 設定画面
- アプリケーションの設定（テーマ、言語など）
- 分析パラメータのカスタマイズ
- ユーザープロファイル管理
