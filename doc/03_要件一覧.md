# 要件一覧

## 1. 機能要件

### 1.1 音声入力・処理要件
- **必須**: ユーザーのマイクからリアルタイムで音声を取得できること
- **必須**: 音声処理の開始/停止を制御できること
- **必須**: 音声データのFFT処理を行い、周波数スペクトルを生成できること
- **必須**: 音声の振幅（RMS）を計算できること
- **必須**: マイク入力を録音し、後で再生できること
- **必須**: 外部の音声ファイル（WAV、MP3など）を読み込み、再生できること
- **必須**: 録音・再生中の音声をリアルタイムで分析できること
- **推奨**: 複数の音声入力デバイスから選択できること
- **推奨**: 音声入力のゲイン調整ができること
- **推奨**: 録音した音声をファイルとしてエクスポートできること

### 1.2 録音・再生要件
- **必須**: 音声の録音を開始/停止できること
- **必須**: 録音中の経過時間を表示できること
- **必須**: 録音した音声を保存し、アプリ内で管理できること
- **必須**: 保存した録音を選択して再生できること
- **必須**: 音声ファイルの再生を開始/一時停止/停止できること
- **必須**: 再生中の位置を視覚的に表示できること
- **必須**: 再生位置を任意の位置に移動（シーク）できること
- **推奨**: 複数の録音を管理できること
- **推奨**: 録音のリネームや削除ができること
- **推奨**: 再生速度の調整ができること

### 1.3 ファイル入力要件
- **必須**: WAV、MP3、OGG、M4A形式の音声ファイルを読み込めること
- **必須**: ファイル選択インターフェースを提供すること
- **必須**: 選択したファイルの基本情報（ファイル名、形式、長さ）を表示できること
- **推奨**: ドラッグ＆ドロップでのファイル読み込みに対応すること
- **推奨**: ファイルのメタデータ（アーティスト名、タイトルなど）を表示できること

### 1.2 ピッチ検出要件
- **必須**: リアルタイムでピッチ（基本周波数）を検出できること
- **必須**: ピッチ検出の精度が±1Hz以内であること
- **必須**: ノイズや無音状態を適切に処理できること
- **必須**: 検出したピッチをHz単位で表示できること
- **必須**: ピッチに対応する音階を表示できること
- **必須**: ピッチを視覚的に表示できること
- **推奨**: 検出感度のパラメータ調整ができること
- **推奨**: 特定の周波数範囲にフォーカスできること

### 1.3 周波数特性分析要件
- **必須**: リアルタイムの周波数スペクトルを表示できること
- **必須**: 基本周波数、2倍音、3倍音を識別・表示できること
- **必須**: 2倍音、3倍音の強度を基音との比率（%）で計算・表示できること
- **必須**: 2.8kHz~3.2kHz帯域の最大成分を基音との比率（%）で計算・表示できること
- **推奨**: 任意の周波数帯域の分析ができること
- **推奨**: スペクトル表示のスケール（線形/対数）を切り替えられること

### 1.4 時間経過分析要件
- **必須**: 時間経過に伴う周波数スペクトルの変化をヒートマップとして表示できること
- **必須**: 一定時間における2倍音、3倍音、特定帯域の平均強度を計算・表示できること
- **推奨**: ヒートマップの時間スケールを調整できること
- **推奨**: 特定時点のスペクトルデータを詳細表示できること
- **推奨**: 時間経過データを保存・再生できること

### 1.5 音声可視化要件
- **必須**: 再生中/録音中の音声波形を表示できること
- **必須**: 再生/録音の進行状況をタイムラインで表示できること
- **必須**: 再生/録音中の音声分析結果をリアルタイムで更新できること
- **推奨**: 波形表示の拡大/縮小ができること
- **推奨**: 特定の時間範囲にフォーカスして詳細分析ができること

### 1.6 UI/UX要件
- **必須**: 直感的で使いやすいユーザーインターフェースを提供すること
- **必須**: レスポンシブデザインでモバイル・デスクトップ両対応であること
- **必須**: 処理状態やエラーを適切にユーザーに通知できること
- **必須**: ダークモード/ライトモードに対応していること
- **推奨**: 多言語対応（日本語/英語）であること
- **推奨**: ユーザー設定を保存・復元できること

## 2. 非機能要件

### 2.1 性能要件
- **必須**: ピッチ検出の遅延が100ms以下であること
- **必須**: 60FPS以上のリアルタイム描画性能を維持すること
- **必須**: CPU使用率が平均30%以下であること
- **必須**: メモリ使用量が500MB以下であること
- **推奨**: バッテリー消費を最適化すること

### 2.2 互換性要件
- **必須**: 最新のChrome、Firefox、Safari、Edgeブラウザで動作すること
- **必須**: デスクトップ（Windows、macOS、Linux）環境で動作すること
- **必須**: モバイル（iOS、Android）環境で基本機能が動作すること
- **推奨**: タブレットデバイスに最適化された表示を提供すること

### 2.3 セキュリティ要件
- **必須**: マイクアクセス権限を適切に管理すること
- **必須**: ユーザーデータを安全に扱うこと
- **推奨**: オフライン動作をサポートすること

### 2.4 拡張性要件
- **必須**: 新しい分析機能を容易に追加できる設計であること
- **必須**: コンポーネントベースのモジュラー構造であること
- **推奨**: サードパーティプラグインをサポートできる設計であること

## 3. 将来的な要件

### 3.1 トレーニング支援要件
- 目標ピッチ/音域の設定と達成度表示機能
- 発声パターンの記録と分析機能
- トレーニングプログラムの提案機能
- 練習履歴の管理と進捗表示機能

### 3.2 音質評価要件
- 声質の特徴分析（明るさ、暗さ、かすれなど）機能
- 声の安定性評価機能
- ビブラート、トレモロなどの技術分析機能
- 声質改善のためのアドバイス生成機能

### 3.3 データ管理要件
- トレーニングセッションの記録と保存機能
- 分析結果のエクスポート（PDF、画像など）機能
- トレーナーとの共有機能
- クラウド同期機能

### 3.4 AIアシスタント要件
- 音声特性に基づくパーソナライズされたアドバイス生成機能
- 声質改善のための具体的な提案機能
- 進捗の自動分析とフィードバック機能
- 音声サンプルとの比較分析機能
